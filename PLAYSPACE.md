# 🎨 Shivali's Playspace

Welcome to your personal Figma + Storybook playground!

## Getting Started

```bash
# Make sure you're on this branch
git checkout playspace/shivali

# Install dependencies
yarn

# Start Storybook
yarn dev
```

## What can you do here?

- **Experiment freely** - This branch is your sandbox, make a mess!
- **Test Figma designs** - Recreate designs using IDS components
- **Try component combinations** - See how components work together
- **Learn the codebase** - Explore without fear of breaking anything

## Useful locations

| What | Where |
|------|-------|
| Components | `packages/components/src/components/` |
| Stories | `*.stories.tsx` files next to components |
| Docs | `packages/components/docs/` |
| Tokens | `packages/tokens/` |

## Quick tips

1. **Find a component** - Check the Storybook sidebar or `packages/components/src/components/`
2. **See how it's used** - Look at the `*.stories.tsx` file
3. **Copy and modify** - Duplicate a story to experiment
4. **Check the docs** - Each component has a `*.docs.mdx` file
