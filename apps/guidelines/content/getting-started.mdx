# Getting Started

## Installation

```bash
yarn add @iress-oss/ids-components @iress-oss/ids-tokens
```

## Basic Usage

```tsx
import { IressButton } from '@iress-oss/ids-components';

function App() {
  return <IressButton>Click me</IressButton>;
}
```
