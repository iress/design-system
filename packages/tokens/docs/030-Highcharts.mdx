# Highcharts Usage Examples

This page demonstrates how to use IDS tokens with [Highcharts](https://www.highcharts.com/) for data visualization. The examples show how to integrate IDS color tokens, typography, and spacing into your charts for a consistent design system experience.

## Why Use IDS Tokens with Highcharts?

Using IDS design tokens with Highcharts provides several benefits:

- **Consistency**: Charts automatically match your brand colors and design system
- **Theming**: Easy to switch themes by updating token values
- **Maintainability**: Central source of truth for design decisions
- **Accessibility**: Use tested, accessible color combinations

## Key Features Demonstrated

Each example demonstrates:

1. **Color Integration**: Using `colour.data.bold`, `colour.primary`, and `colour.system` tokens for chart colors
2. **CSS Variables**: Using `cssVars` directly for dynamic theming support
3. **Typography Styling**: Applying IDS typography tokens to chart labels and legends
4. **Layout & Spacing**: Using design tokens for consistent padding and margins

## Handling More Than 9 Series

### Is it OK to have more than 9 series in one chart?

For the majority of UI dashboards and business charts:

- **3 to 7 series is the sweet spot**
- **8 to 9 is already pushing cognitive load**
- **Beyond 9, users stop comparing and start squinting**

In practice, many products deliberately cap at ~6–8 series because:

- Legends get crowded
- Color discrimination drops sharply
- The chart becomes a decoding exercise instead of insight

If your charts are:

- KPI dashboards
- Time series comparisons
- Category comparisons meant for decision-making

Then 9 colors is usually enough.

### What to do when 9 colors isn't enough?

Color should stop doing all the work. Here are practical escape hatches:

#### 1. Reuse colors with structure (recommended)

After color 9, cycle back but vary something else:

- **Line style**: solid, dashed, dotted
- **Marker shape**: circle, square, diamond
- **Opacity levels**
- **Stroke width**

This works especially well for:

- Line charts
- Area charts
- Overlaid comparisons

**Color identifies the "family"; style disambiguates siblings.**

See the **Line Chart - 20 Series with Patterns** example above for a practical implementation.

#### 2. De-emphasize the long tail

Let the important series shine, mute the rest:

- Top 5–7 series get distinct colors
- Remaining series use neutral greys or a single muted color
- Highlight on hover or selection

This mirrors how people actually read charts: hero first, background later.

#### 3. Group or aggregate categories

If a chart needs 14 colors, that's often a smell. Options:

- Combine smaller categories into "Other"
- Allow drill-down instead of showing everything at once
- Use small multiples instead of one mega-chart

Clarity usually improves, not suffers.

## Getting Started

To use IDS tokens with Highcharts in your project:

1. Install the required packages:

```bash
npm install @iress-oss/ids-tokens highcharts highcharts-react-official
```

2. Import the tokens and Highcharts:

```jsx
import { cssVars } from '@iress-oss/ids-tokens';
import Highcharts from 'highcharts';
import HighchartsReact from 'highcharts-react-official';
```

3. Use IDS tokens directly in your chart options:

```jsx
const options = {
  colors: [
    cssVars.colour.data.bold['10'],
    cssVars.colour.data.bold['30'],
    cssVars.colour.data.bold['50'],
  ],
  chart: {
    backgroundColor: cssVars.colour.neutral['10'],
  },
  // ... more configuration
};
```

The `cssVars` object provides CSS variable strings in the format `var(--iress-colour-primary-fill, #003271)`, which Highcharts supports natively. This allows for dynamic theming and respects the CSS cascade.

## Available IDS Color Tokens for Data Visualization

The IDS design system provides specific color palettes for data visualization:

- **Bold Colors** (`colour.data.bold`): 10, 20, 30, 40, 50, 60, 70, 80, 90 - High contrast colors for charts
- **Subtle Colors** (`colour.data.subtle`): 10, 20, 30, 40, 50, 60, 70, 80, 90 - Softer colors for backgrounds
- **System Colors**: `primary`, `success`, `info`, `warning`, `danger` - Semantic colors
- **Neutral Colors**: 10-90 scale for backgrounds, text, and borders
