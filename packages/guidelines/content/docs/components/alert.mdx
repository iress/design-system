## When To Use

- When you need to show alert messages to users.
- When you need a persistent static container which is closable by user actions.

### When Not To Use

- For transient messages that auto-dismiss → [Toaster](/docs/components/toaster)
- For inline field-level errors → [ValidationMessage](/docs/components/validation-message)
- For blocking actions that require user confirmation → [Modal](/docs/components/modal)

## Examples

### Status

The alert offers four statuses that set a distinctive colour and icon. They can be set using the `status` prop.

<StorybookEmbed storyId="components-alert--status" code={`<IressAlert status="info">Info alert</IressAlert>
<IressAlert status="success">Success alert</IressAlert>
<IressAlert status="warning">Warning alert</IressAlert>
<IressAlert status="danger">Danger alert</IressAlert>
<IressAlert status="neutral">Neutral alert</IressAlert>`} />

### Heading

An alert can be displayed with a heading via the `heading` prop. If provided a string, it renders a `<h2 />`. If provided a React element, it renders that directly.

<StorybookEmbed storyId="components-alert--heading" code={`<IressAlert heading="Alert heading" status="info">
  This is an alert with a heading.
</IressAlert>`} />

### Actions

The `actions` prop displays call to action buttons within the alert, providing users with options to take action based on the alert message.

<StorybookEmbed storyId="components-alert--footer" code={`<IressAlert
  heading="Confirm"
  status="danger"
  actions={[
    { children: 'Cancel', mode: 'tertiary' },
    { children: 'Confirm', mode: 'secondary' },
  ]}
>
  Are you sure you want to proceed?
</IressAlert>`} />

### Icon

The `icon` prop customises the icon displayed. It accepts a string for the icon name, or `false` to remove the icon entirely.

<StorybookEmbed storyId="components-alert--icon" code={`<IressAlert icon={false} heading="No icon" multiLine>
  This is an alert without an icon.
</IressAlert>`} />

### Multi-line

Set `multiLine` to `true` for longer content. This adjusts spacing and aligns the icon to the top of the alert.

<StorybookEmbed storyId="components-alert--multi-line" height={500} code={`<IressAlert multiLine heading="Alert heading" status="danger">
  Once you confirm, the system will begin re-indexing your
  entire library, which may temporarily limit access...
</IressAlert>`} />

### Variants

The `variant` prop changes the alert layout:

- `sidebar` — for informational messages on longer forms
- `full-width` — for site-wide banners

<StorybookEmbed storyId="components-alert--variant" code={`<IressAlert variant="sidebar" heading="Did you know?">
  You can use the alert component in different ways.
</IressAlert>
<IressAlert variant="full-width" heading="Did you know?">
  You can use the alert component in different ways.
</IressAlert>`} />

### Dismissable

Set `onClose` to make the alert dismissable. This displays a close button in the top right corner.

<StorybookEmbed storyId="components-alert--dismissable" code={`<IressAlert
  status="info"
  onClose={() => console.log('dismissed')}
>
  This is a simple info alert
</IressAlert>`} />
