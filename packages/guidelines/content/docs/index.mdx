Welcome to the Iress Design System documentation.

## Getting Started

Install the IDS component library:

```bash
yarn add @iress-oss/ids-components @iress-oss/ids-tokens
```

Wrap your application with `IressProvider`:

```tsx
import { IressProvider } from '@iress-oss/ids-components';
import '@iress-oss/ids-components/style.css';

function App() {
  return (
    <IressProvider>
      <YourApp />
    </IressProvider>
  );
}
```
