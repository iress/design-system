# Agent Skills

Agent skills give AI coding assistants (GitHub Copilot, Claude Code, Cursor, Codex, and [37+ more](https://github.com/vercel-labs/skills#supported-agents)) contextual knowledge about the Iress Design System — components, design tokens, styling patterns, and best practices.

Skills are installed as static files alongside your project. No runtime server, no Playwright, no Storybook dependency.

---

## Available Skills

| Skill                 | Description                                                                                     |
| --------------------- | ----------------------------------------------------------------------------------------------- |
| **figma-to-ids**      | Translate Figma design properties and structures into IDS component implementations             |
| **token-usage**       | Guide on correctly using IDS design tokens in React components and CSS                          |
| **ui-doctor**         | Audit and validate that an application correctly uses IDS components and follows IDS principles |
| **ui-translation**    | Translate natural language UI descriptions into IDS component implementations                   |
| **version-migration** | Guide on migrating between IDS major versions (v4→v5, v5→v6, OUI→v6)                            |

## Installation

Install skills using the open-source [skills CLI](https://github.com/vercel-labs/skills):

### Quick Start

```bash
# Install all IDS skills (interactive — choose your agents)
npx skills add iress/design-system
```

### Install Specific Skills

```bash
# Install only the token-usage skill
npx skills add iress/design-system --skill token-usage

# Install multiple specific skills
npx skills add iress/design-system --skill token-usage --skill figma-to-ids
```

### Install to Specific Agents

```bash
# GitHub Copilot
npx skills add iress/design-system -a github-copilot

# Claude Code
npx skills add iress/design-system -a claude-code

# Cursor
npx skills add iress/design-system -a cursor

# Multiple agents at once
npx skills add iress/design-system -a github-copilot -a claude-code -a cursor
```

### Other Commands

```bash
# List available skills before installing
npx skills add iress/design-system --list

# List installed skills
npx skills list

# Update all installed skills
npx skills update

# Remove skills
npx skills remove
```

---

## How It Works

Skills are `SKILL.md` files that get installed into your project (or globally). Your AI coding assistant reads them automatically and uses the knowledge when helping you write code.

**How it works:**

- Static markdown files — zero runtime dependencies
- Works with 37+ AI coding agents out of the box
- Installed once, updated with `npx skills update`

## llms.txt

The `llms.txt` files provide a machine-readable index of IDS documentation for LLM-based tools. These follow the [llms.txt standard](https://llmstxt.org/) and are located at:

- [`packages/components/llms.txt`](https://github.com/iress/design-system/tree/main/packages/components/llms.txt) — Component documentation index
- [`packages/tokens/llms.txt`](https://github.com/iress/design-system/tree/main/packages/tokens/llms.txt) — Design token documentation index

These files list all available documentation with links to the detailed `.ai/` markdown files, making it easy for AI tools to discover and reference IDS documentation.
