## Usage

`IressPanel` uses `IressCard` under the hood, so it inherits all of the same props and styling options. However, `IressPanel` has some default styles applied to it, such as padding and a background color.

<IressButton href="/?path=/docs/components-card--docs">
  View the API documentation for `IressCard`
</IressButton>

### When to use

Panels are used to group related content. They can be used to create sections within a page, as well as group lists of items together.

- If you need to display micro-content, use [IressCard](/?path=/docs/components-card--docs) instead.
- If you need to add padding or a background to a section of content, use [IressStyled](/?path=/docs/styling-props-reference--docs) on the component itself.
- Otherwise, use `IressPanel` to group related content together.
