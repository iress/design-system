## When to use

Use badges for **status indication and notifications** where information needs to be highlighted:

- Notification counts (e.g., unread messages, pending items)
- Status indicators (success, warning, danger, info)
- "New" or "Updated" labels
- Drawing attention to important information
- Quick visual highlights that don't require user interaction

Badges are **informational** - they display information but are not meant to be interactive.

**Not sure?** If users need to interact with items (click, delete, or manage selections), use [Tag](/?path=/docs/components-tag--docs) instead.
